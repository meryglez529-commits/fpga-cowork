# RTL 设计指导

形成能够指导 RTL 编码、便于评阅的设计方案。图表呈现结构和工作过程，文字紧跟
对应图表，补充实现理由、约束和图表难以表达的行为含义。同一行为的详细解释
集中一处，图表保留各自必要的标注。

设计分两步：先提交总体方案，确认后展开模块内部方案。已有确认的总体方案时直接
进入第二步；复杂项目每轮只展开一个模块。

设计中的新建模块和端口按[代码风格规范](rtl-coding-standard.md)命名；已有外部接口
名称保持不变。已确认的模块内部方案作为 RTL 编码依据，编码时保持其中的功能、
接口和周期约定，并按[编码检查](rtl-checks.md)完成检查。

## 第一步 总体设计

明确功能、输入输出、影响架构的约束及可复用模块或 IP。按相对完整、职责明确的
功能单元划分模块，结合数据流、控制联系、接口、时钟域和复用需要说明划分理由。

交付总体框图和模块功能表，讲清各模块怎样协作完成一次完整工作过程。图中无法
说明清楚的模块间交接行为用简表或文字补充；已有协议和功能定义引用需求。
存在影响模块划分、接口、时钟域或跨模块处理能力的具体选择时，做必要核算并说明
结论如何支持该选择。模块内部算法、参数、状态、计数和详细时序留到第二步。

## 第二步 模块内部设计

以已确认的模块职责和接口为边界，按模块接口图、端口表、实现方法、状态机图
（采用状态机时）及必要时序图展开。

从完整功能过程推导控制与数据处理方法，解释为什么采用状态机、流水、并行或
复用。将操作对应到状态、步骤或处理阶段，讲清划分依据、推进条件及关键实现：
计数怎样推动操作，数据何时处理、保存或输出，各部分怎样配合。

位宽、数值处理、存储访问、流水对齐、等待、复位和异常处理，按实际功能与约束
需要展开；取舍处说明理由和主要代价。复杂内部结构沿用总体框图的画法，按需展示。
具体 RTL 赋值和常规辅助信号留到编码。

用计算、周期推演或参考模型核对新增方案的关键判断，已确认的依据直接引用。
复杂控制或多个相关场景优先用模块级 Python 逐拍模型；简单过程可用逐拍表。
实际资源和时序由 RTL 实现后的报告确认。若需改变已确认的模块边界或接口，说明
影响并返回总体方案确认。

## 四类图的统一画法

| 图的类型 | 表现方式 | 固定工具 |
| --- | --- | --- |
| 总体框图 | 模块用矩形表示，框内只写名称；按实际端口连接模块，画出顶层边界、外部接口和时钟域。每个实例画一次 | 端口连线式 SVG 模板 |
| 模块接口图 | 一个矩形框，框内只写模块名称；输入在左、输出在右，双向端口用双向箭头；端口按用途排列 | 同一 SVG 模板 |
| 状态机图 | 圆内写状态名及必要的简短动作，按主要流程沿圆周排列；完整箭头标转移条件，自环朝外，复位指向初态 | 固定环形 SVG 模板 |
| 时序图 | 信号名称在左，波形在右，共用时间轴；选取解释操作所需的时钟、状态、控制和数据，标明采样、更新与完成位置 | [WaveDrom](https://wavedrom.com/tutorial.html) |

两类框图先安排端口位置和顺序，再确定框的尺寸、间距与连线路径。每个信号或总线
独立连线，用直线或直角折线，箭头指向接收端；在线旁标名称和位宽，多位写作
`data[15:0]`，单比特只写名称。同一信号分支用实心连接点，不相连的线交叉不画点。
公共时钟、复位可用母线或注明适用范围；多时钟域按模块标注。

四类图共用[绘图入口](../scripts/render_rtl_diagram.cjs)，运行 `--help` 查看图源格式，
`--check` 检查已准备的依赖。状态图使用 JSON 图源填写状态、流程顺序和转移条件，由模板生成节点、
完整连线和标注；状态关系按实际设计保留。
时序图统一接受模型导出数据或人工逐拍表，记录数据来源和省略区间。
模块接口图由端口表生成；总体框图用图源指定模块、端口和连接位置，复用渲染代码。
图统一使用白底、细线和一致字号，标注以文档正常阅读尺寸清楚可辨为准。

时序按完整操作组织，长过程先给总览，再按需要放大关键阶段；省略区间标明实际
拍数或时间；其他场景突出变化的信号与交接行为。注明设计预期波形或仿真波形的性质。

表格使用 Markdown：模块功能表写名称、功能和划分理由；端口表写信号名、方向、
位宽、功能及必要的有效条件。状态动作较多时用表补充控制、数据更新和输出行为。

## 核对与交付

沿完整工作过程通读：第一步检查模块划分、连接和协作是否清楚，足以进入模块内部
设计；第二步检查实现方法与关键行为是否明确，足以指导编码。未解决的问题说明影响。
图表直接显示在文档中；自查可直接阅读 Markdown 并查看 SVG/PNG，其他预览按需采用。
修正设计矛盾和遗漏。图的验收以关系正确、连线完整、文字可读为准；断线、错连和
条件无法辨认必须修正。轻微压线及不影响理解的布局差异可接受，达标后结束排版调整。

保留可重新生成的图源与 SVG 成品，预览图片按显示需要生成。正文仅保留关键核对
结论和图源入口；辅助模型、绘图脚本及详细运行记录另存。
