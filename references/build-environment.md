# B — Vivado 构建

在用户指定的 `.xpr` 中完成综合、实现、构建验收或镜像生成，沿用已登记输入、top 和 run。

## 准备

确认相关 RTL、XDC、IP、Block Design 和调试设计已登记并保存，目标 run 和 compile order
正确。明确本次目标阶段及评价指标，选择满足目标的必要阶段。

已有结果仍匹配当前输入并满足目标时复用；需要重做时从受影响阶段运行。确认目标 run
没有被其他实际工作进程执行。

## 执行

使用工程现有 run 完成目标阶段，等待实际工作进程与 run 得到明确结束状态。外层调用转入
后台或异常结束不代表 run 已停止；恢复前确认实际状态，只处理受影响对象，保留仍有效结果。

原生日志、检查点、报告及生成的 bit/LTX 沿用 `<工程>.runs/`。补充报告写入对应 run 目录。

按目标检查完成状态、相关错误与警告、约束覆盖、时序、路由和 DRC。警告按实际影响解释；
无有效路径或约束覆盖不足时说明限制。交付 bit/LTX 时确认来自同一次有效实现并对应输入。

## 结果

按实际阶段报告 run 状态、相关验收指标、限制和原生产物入口。交付镜像时给出可检查身份。
构建结论只覆盖所检查的指标，功能及板级行为由相应证据说明。
