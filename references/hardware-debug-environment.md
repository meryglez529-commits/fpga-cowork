# H — Vivado 硬件、ILA 与 VIO

通过用户指定 `.xpr` 的 Hardware Manager 完成 JTAG、下载、ILA、VIO 或 Flash 操作。

## 准备

明确本次操作、观察目标和结束条件，确认实际 target、device 及 FPGA part。多个候选按
已确认身份选择；无法确定时请用户指定。

按目标准备输入：枚举或读取已有状态不要求镜像；下载需要 bit；ILA/VIO 使用同一次实现
的匹配 bit/LTX，并核对实际调试核、`CELL_NAME` 和 probe 宽度。需要镜像时确认它对应
当前工程输入，缺失或不匹配时停止该项操作并说明缺口。

确认工作区未被其他实际会话占用，新采集使用可辨识的唯一文件名，保留已有结果。

## 执行

在精确目标器件上关联并核对镜像和调试文件，刷新后确认实际调试对象与设计一致。
Vivado 2021.1 中同步设置并读回 `PROBES.FILE` 与 `FULL_PROBES.FILE`，下载前后确认
其指向本次匹配 LTX，并显式刷新调试核。

镜像仍匹配时复用已下载配置，连续硬件验证优先复用可用会话。运行时触发参数变化不使
镜像过期；影响实现输入或调试核结构的变化需要重新判断镜像有效性。

ILA 使用明确触发条件、采样窗口和有限等待；VIO 使用明确对象和值并读回可观察状态。
原生 ILA 数据及需要的导出沿用 `<工程>.hw/`。对象或镜像不匹配时停止对应操作。

JTAG 下载按易失配置处理；用户请求或模块设计明确包含 Flash 时，按指定器件、镜像和地址操作。

## 结果

按任务说明实际目标、镜像及可检查身份、执行操作、采集入口与板卡最终配置。
硬件结论对应本次镜像、探针、触发条件及采样范围，只证明实际观察到的板级行为。
