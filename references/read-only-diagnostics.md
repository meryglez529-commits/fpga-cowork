# D — 只读诊断

从既有代码、工程状态、报告、日志、镜像身份或采集中解释当前问题。

## 准备

明确问题和判断标准，选择所需的源、工程对象及已有证据，确认其路径、生成身份和适用范围。

## 执行

沿代码、时钟/复位、约束、工具结果或采样数据建立证据关系。
保持工程输入、run、仿真和硬件状态不变，现有证据不足时说明缺口。
需要新的仿真、构建或硬件证据时，由任务另行选择相应流程。

## 结果

给出关键证据及原始路径，区分已证实、推测和无法确定的结论，说明范围与所需下一步。
结论留存按[工程上下文](project-context.md)处理；具体执行分析保留在原始日志或对话中。
