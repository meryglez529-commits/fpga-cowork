# D — 只读诊断

D 用于解释既有 RTL、XDC、IP、Block Design、工程状态、报告、日志、bit/LTX 身份或已有
ILA 数据。它从用户指定 `.xpr` 及其原生产物中选择回答当前问题所需的最小证据。

## 执行

1. 明确需要回答的问题和判断标准。
2. 定位实际使用的源文件、fileset、run、报告、日志或采集，并记录绝对路径和生成身份。
3. 沿代码层次、时钟/复位、约束、工具结果或采样数据建立证据链。
4. 区分已证实、可能和现有证据无法确定的结论，说明影响范围与最小下一步。

D 保持工程输入、run、仿真和硬件状态不变。现有证据不足时，报告需要补充的证据类型并
结束当前诊断，不在 D 中启动其他流程。

## 结果

在对话中给出所查原始路径、关键证据、结论级别、适用范围和下一步。用户要求留存时，
把高密度结论更新到所属模块的现有文档或用户指定的记录中。
